# Migrations: 2.14.47

API and behaviour changes in 2.14.47 that need a consumer adjustment. Older releases are in [migrations.md](../migrations.md) and this folder.

## An HTTP receive body has a 30 s deadline (BEHAVIOUR CHANGE)

The HTTP source read a request body for as long as the sender took, holding the bytes it reserved from `max_in_flight_bytes`. `body_timeout_ms` (default 30000) now bounds the read once the headers have arrived. A slower body fails its request and frees its bytes. The held answer of an armed receiver is not bounded by it.

**Consumer adjustment** -- none for most apps. A receiver that takes very large uploads over slow links raises `body_timeout_ms`, or sets it to `0` for no deadline.
